## Codebase Patterns

### Model Architecture
- Model uses class mixin pattern: `class User extends Model(usersTable)`
- Static properties on subclass accessible via `this.constructor`
- Proxy pattern for dynamic attribute access
- `ModelStatic` type for static class reference

### Existing Hook Points (in model.ts)
- `save()` method handles both create (new records) and update (persisted records)
- `destroy()` method handles deletion
- `_persisted` flag distinguishes new vs existing records
- Validation hooks pattern: `static validations = {...}` can inform hook design

### Test Patterns
- Unit tests: `*.test.ts` with mocked DB connection
- Integration tests: `*.integration.test.ts` with real Postgres
- Test setup in `setup.integration.ts`
- Global setup in `globalSetup.integration.ts`

### Key Files
- `src/lib/activerecordjs/model.ts` - Core model, will add hook execution here
- `src/lib/activerecordjs/types.ts` - Add hook type definitions here
- `src/lib/activerecordjs/fixtures/models.ts` - Test models, add hooks here for testing
